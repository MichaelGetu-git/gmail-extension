How opens are counted

An open is counted when a recipient's mail app loads the Zemenay logo in the email's footer. The extension leaves your own views out; server-side numbers can't tell them apart. Treat the rate as an estimate: Apple Mail loads every image on arrival, so its users count as opened whether or not they read it, and many company inboxes block images, so some real reads never show. Replies are the number to trust.

Accounts

Sends from the server over Gmail SMTP with each account's app password. An account pauses itself on a login failure, 3 failures in a row, or a bounce rate above 5%. The Lane column decides which contacts an account sends: Regular (the main Contacts list), Work or Hot (the Hot leads page). Lanes never mix.

Add a sending account

Gmail or Google Workspace addresses (sent through smtp.gmail.com). The account sends nothing until its app password is set in Vercel (the variable name is shown after adding) and the project is redeployed; sending also stays under the global pause.

Schedule and safety

Times are Africa/Nairobi (EAT, UTC+3). Each account gets its own random start inside the window every sending day, then sends its quota with random gaps. Follow-ups count toward the cap.

Upload contacts (CSV)

Contacts go into the Regular lane (the main list). You see a preview with every check before anything is imported. Everyone is checked against every suppression source on upload, when the day is planned, and again right before sending.

Suppression

Never emailed: the contacted lists bundled at deploy, imported lists, opt-outs and unsubscribes, the extension's history, extension-claimed leads, the Lead Desk (if it shares this database) and everyone the server already emailed.

Delete test data

Removes only the addresses you list (a test upload, your own inboxes) from the dashboard's data: contact, queue and day plans, sends, opens, replies and their send-log entries, so the rates count real prospects only. Everyone else's data is untouched. Suppression lists are kept. You see exactly what will go before anything is deleted, and a backup is kept for 180 days.

Lane

Work and Hot leads are kept apart from the main Contacts list. Each lane only ever sends from the accounts assigned to it (Sending → Accounts → Lane); a lane with no account sends nothing and never borrows a Regular account. Suppression, opt-outs, the do-not-email lists, the global pause, the schedule window and the test-recipient list apply to every lane.

Upload leads (CSV)

Same format as the main upload. Leads go into the lane picked above; someone already in another lane (or the main Contacts list) is skipped with the reason shown, and everyone is checked against every suppression source. You see a preview before anything is imported.
